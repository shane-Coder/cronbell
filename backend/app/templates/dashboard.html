Get your first monitor running

  1. Create a monitor below. Pick a use case, or set your own name and interval.
  2. Copy its ping URL from the monitor's page once it's created.
  3. Add one line to your job: curl -fsS <your-link>, run only on success.

That's it — Cronbell emails you (and Slack/Discord/webhook, if you set those up) the moment a ping doesn't arrive on schedule.

What is Cronbell, exactly?

A heartbeat monitor for automated tasks instead of a person. Your job pings Cronbell when it finishes; if that ping goes quiet, you get alerted — before you find out the hard way, days later.

Same idea as Healthchecks.io or Cronitor, self-hostable and open here. It doesn't replace Prometheus/Grafana — they watch live services, this watches jobs that only run occasionally.
