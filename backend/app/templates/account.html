Public status page

Anyone with this link sees the name, status, and uptime of whichever monitors you've checked "show on my public status page" for — nothing else, no ping URLs or notes. Toggle it per monitor on that monitor's edit page.

{{ request.base_url }}status/{{ user.status_page_token }}

Prometheus / Grafana

Scrape this URL to get your monitors' up/down state, last-ping time, and expected interval as Prometheus metrics — good for pinning them on an existing Grafana dashboard alongside everything else you already watch. It's scoped to your account only, so treat the URL as a secret, same as a ping URL.

{{ request.base_url }}metrics/{{ user.metrics_token }}

Example prometheus.yml scrape config:

scrape_configs:
  - job_name: cronbell
    metrics_path: /metrics/{{ user.metrics_token }}
    static_configs:
      - targets: ["{{ request.base_url.hostname }}"]
    scheme: https
